# Automated STEP File Processing

**CAD Automation & Engineering Data Processing**

**Technologies:** Python, pythonOCC, STEP CAD, FastAPI

## Overview

A CAD automation project focused on processing
STEP files and extracting structured engineering
information from 3D models to test.

The project was developed through my work at
KnowYi Technologies, where I contributed to
automating engineering data extraction and testing process, 
supporting manufacturing information workflows.

## Key Features

### 1. STEP File Processing

- Parse STEP CAD files using Python and pythonOCC.
- Access geometric and topological information
  from imported 3D models.
- Extract part-level metadata for further processing.

### 2. Automated Data Extraction

- Process engineering information without
  requiring manual inspection of each model.
- Organize extracted geometry and metadata
  into structured formats.
- Support downstream data-processing workflows.

### 3. Backend Integration

- Integrate CAD processing functionality
  with Python-based backend services.
- Support API endpoints for engineering
  information extraction.
- Enable extracted data to be used
  by other automation workflows.

## Technical Approach

The workflow follows three main stages:

1. **Input:** Import STEP CAD files.
2. **Processing:** Use pythonOCC to access model
   geometry, topology, and part information.
3. **Output:** Organize extracted information
   into structured data for downstream use.
